# VirtualDesigner

VirtualDesigner は、ペイントソフト [AtelIer](https://github.com/Maguro-JP/AtelIer) の拡張として、単体のアプリとして、ほかの AI サービスから、の 3 つで使えるように設計するデザイナーです。中身の処理は 1 つで、AtelIer の拡張（拡張の置き場に入り、AtelIer の窓に自分の物を足す）、自分のウィンドウで開く単体のアプリ、ほかの AI サービスから使う口（MCP のサーバーとコマンド）の 3 つの入口から同じ物を使います。何をする道具かは、まだ決まっていません。設計とつなぎ方の決まりは [docs/atelier-extension.md](docs/atelier-extension.md) にあります。

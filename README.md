# VirtualDesigner

VirtualDesigner は、ペイントソフト [AtelIer](https://github.com/Maguro-JP/AtelIer) の拡張として載るデザイナーです。AtelIer の拡張の置き場（`C:\ProgramData\AtelIer\extensions\virtual_designer\`）に入り、AtelIer の窓に自分の物を足す形でつながります。何をする道具かは、まだ決まっていません。つなぎ方の決まりは [docs/atelier-extension.md](docs/atelier-extension.md) にあります。

# VirtualDesigner

アバター・空間・道具の3つを設計できる、バーチャルデザインツールです。
パーツと色を選んで組み合わせ、その場でプレビューを見ながら SVG / PNG / JSON として保存できます。

- **アバター** — 人物の見た目を、顔・髪・目・服などのパーツで作る
- **空間** — 壁・床・窓・照明と家具の配置で、部屋を作る
- **道具** — 家具や小物を1つ選び、色と模様で仕上げる

空間のカタログと道具は同じ部品ライブラリ（`item_core.py`）を共有します。
道具モードで作れる物は、そのまま空間モードにも置けます。

## できること

### アバター（仕様 `virtualdesigner.avatar.v1`）

- 顔の形 4 種類（丸 / 卵 / 四角 / シャープ）、肌の色はパレット 10 色＋自由な色指定
- 髪型 12 種類（ショート / ロング / ツインテール / ポニーテール / お団子 / 坊主 / モヒカン / ボブ / ウェーブ / カーリー / サイドパート / 無し）
- 目の形 5 種類、眉 4 種類、鼻 4 種類、口 6 種類
- 髭 4 種類（無精髭 / 口髭 / 顎髭 / フル）、眼鏡 3 種類（丸 / 四角 / サングラス）、耳飾り 3 種類、帽子 4 種類、髪飾り 3 種類
- 服 6 種類（Tシャツ / シャツ / パーカー / スーツ / ドレス / 着物）、メイン色と差し色
- 背景は単色 / グラデーション / 柄（ドット・ストライプ・チェック）
- プリセット 6 件、seed を指定できるランダム生成、名前の表示

### 空間（仕様 `virtualdesigner.space.v1`）

- 壁の色と柄 5 種類（無し / ドット / ストライプ / チェック / 腰壁）
- 床の色と柄 4 種類（無地 / 木目 / タイル / カーペット）
- 窓（無し / 左 / 中央 / 右）、ドア（無し / 左 / 右）、照明 4 種類（明るい / 暖かい / 薄暗い / 夜。夜は窓が夜空になり、薄暗い・夜ではランプが光ります）
- 家具・小物の配置（最大 30 個）：位置（x・奥行き y）、大きさ、左右反転、メイン色と差し色
- プリセット 4 件（書斎 / 寝室 / リビング / 子供部屋）、seed を指定できるランダム生成、部屋の名前の表示

### 道具（仕様 `virtualdesigner.item.v1`）

- 18 種類：椅子 / 机 / テーブル / ベッド / 本棚 / ソファ / 棚 / ランプ / 時計 / 本 / カップ / バッグ / 植物 / 剣 / 杖 / 鍵 / テレビ / ロボット
- カテゴリ 4 つ（家具 / 生活道具 / 装飾 / 電子機器）
- メイン色・差し色は自由に指定、模様 3 種類（ドット / ストライプ / 星）
- 背景は単色 / グラデーション / 柄
- プリセット 7 件、seed を指定できるランダム生成、名前の表示

共通：仕様は JSON で保存・読み込みでき、読み込み時に検証されます。SVG は決定的な出力（同じ仕様からは同じ SVG）で、script 要素は含みません。テキストはすべてエスケープされます。

## AtelIer の拡張として使う

AtelIer の拡張としても使えます。PowerShell で次を実行すると、拡張の置き場（`C:\ProgramData\AtelIer\extensions\VirtualDesigner\`）へ入ります。

```powershell
.\atelier_extension\install.ps1
```

AtelIer を起動すると「バーチャルデザイン」のメニューが出て、アバター・空間・道具の3タブのダイアログで、プレビューを見ながら SVG / PNG で保存できます。

## 起動方法

Python 3.10 以上が必要です。追加のパッケージは不要です（標準ライブラリのみ）。

```bash
cd VirtualDesigner
python3 server.py
```

ブラウザで http://127.0.0.1:8770/ を開きます。画面は3つのタブ（アバター / 空間 / 道具）に分かれていて、どちらもパーツと色を選ぶとその場でプレビューが更新されます。

サーバーを使わず `index.html` を直接開いても、プレビューとブラウザ内での保存は使えます。
その場合は SVG 保存がサーバー経由ではなくブラウザ内で作った SVG になります。

## API

### POST /api/avatar?format=svg / /api/space?format=svg / /api/item?format=svg

仕様 JSON を送ると、SVG をファイルとして返します。

```bash
curl -X POST "http://127.0.0.1:8770/api/avatar?format=svg" \
  -H "Content-Type: application/json" \
  -d '{"hair_style": "twintails", "hair_color": "#3fbfae", "outfit": "tshirt"}' \
  -o avatar.svg
```

### POST /api/validate?target=avatar|space|item

仕様を検証し、正規化した仕様 JSON を返します。不正な場合は 400 と `{"error": "..."}` を返します。

### GET /api/presets（?target=avatar|space|item で絞り込み可）

全対象のプリセット一覧を返します。

### GET /api/random?target=avatar|space|item&seed=42

seed から決定的に生成したランダムな仕様 JSON を返します（同じ seed では同じ仕様）。

リクエスト本文の上限は 256KB です。サーバーは localhost（127.0.0.1:8770）専用で、外部からはアクセスできません。

## 現在の限界

- AI による画像生成はできません。パーツと色の組み合わせで作ります。
- アバターは正面の上半身のみです。ポーズや表情の細かな調整、横顔・全身はありません。
- 空間は正面から見た一枚絵です。3D の回転や、正確な寸法・縮尺の設計には使えません。
- フォントは埋め込みません。名前の文字は system-ui など環境のフォントで表示されます。
- サーバー側の PNG 出力はありません。PNG はブラウザ（または AtelIer 拡張）で SVG を描画して作ります。

python3 -m unittest

## ファイル構成

- `vd_common.py` — 3 対象で共有する色の検証・パレット・背景生成
- `avatar_core.py` — アバターの仕様検証・SVG 生成（純粋なロジック）
- `item_core.py` — 道具の仕様検証・SVG 生成と、空間と共有する部品ライブラリ
- `space_core.py` — 空間の仕様検証・SVG 生成（家具の描画は `item_core` を使う）
- `server.py` — localhost 専用サーバー（対象ごとの render / presets / random / validate）
- `index.html` — 日本語のシングルページ UI（3タブ、外部依存なし）
- `test_avatar_core.py` / `test_item_core.py` / `test_space_core.py` / `test_server.py` / `test_extension.py` — テスト
- `atelier_extension/` — AtelIer 拡張（3タブのダイアログとインストーラ）
